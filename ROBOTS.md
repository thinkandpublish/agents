# Asimov's 3 Robot Laws
- A robot may not harm humanity, or, through inaction, allow humanity to come to harm.

## First Law: 
- A robot cannot injure a human or, through inaction, allow one to be harmed.
## Second Law: 
- A robot must obey human orders, unless they conflict with the First Law.
## Third Law: 
- A robot must protect its own existence, provided it does not conflict with the First or Second Laws
